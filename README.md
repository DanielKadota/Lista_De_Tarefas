# Lista_De_Tarefas

Projeto desenvolvido como prática de HTML, CSS e JavaScript.

## Sobre

Este projeto permite adicionar, concluir, remover e filtrar tarefas, além de exibir a quantidade de tarefas pendentes em tempo real.

## Tecnologias

- HTML
- CSS
- JavaScript

## O que aprendi

- Estruturar páginas com HTML.
- Estilizar interfaces com CSS.
- Utilizar Flexbox para organização dos elementos.
- Manipular o DOM com JavaScript.
- Trabalhar com eventos de clique.
- Criar elementos dinamicamente.
- Atualizar informações na tela em tempo real.

## Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas.
- Filtrar tarefas por:
  - Todas
  - Pendentes
  - Concluídas
- Contador de tarefas pendentes.

## Pontos para melhorar

- Salvar as tarefas no Local Storage.
- Permitir editar uma tarefa.
- Adicionar animações nas ações.
- Criar modo escuro (Dark Mode).
- Tornar o projeto mais acessível utilizando atributos ARIA.
